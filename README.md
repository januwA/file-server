## file-server

一个简单的本地文件目录服务器：给定一个本地目录，启动 Web 服务并以网格页面预览其中的视频、音频、图片与子目录。

### 特性
- 轻量、零配置即可运行
- 自动识别文件类型并渲染视频/音频/图片预览
- 懒加载媒体资源，减少首屏带宽
- 支持为视频动态生成首帧海报（依赖 ffmpeg）

### 环境要求
- Node.js 18+ 运行环境  # 需要支持 ES 模块与原生 fetch 等
- 可选：`ffmpeg`  # 仅当使用视频海报功能时需要

### 安装与构建
```bash
npm install                 # 安装依赖
npm run build               # 编译 TypeScript -> dist
npm start                   # 以 dist/index.js 启动服务
```

开发模式（热启动）：
```bash
npm run dev                 # 使用 tsx 直接运行 src/index.ts
```

### 快速开始
- 假设你希望共享目录 `C:\apps`：

```powershell
node .\dist\index.js "C:\apps"   # Windows 示例：启动并服务该目录
```

或在类 Unix 环境：
```bash
node dist/index.js "/Users/me/Movies"   # macOS/Linux 示例：启动并服务该目录
```

启动后，终端会输出本机访问地址（例如 `http://192.168.1.8:19992`），在浏览器中打开即可查看。

### 使用说明
- 位置参数：
  - 必填：要共享的本地目录的绝对路径  # 程序仅接受一个目录路径作为最后一个参数
- 访问路径：
  - 目录会以“文件夹/文件”的形式呈现  # 点击文件夹可进入子目录
  - 支持的媒体类型会以 `<video>/<audio>/<img>` 预览  # 其他类型显示为可点击的文件/目录链接

### 可选功能
- 视频海报（首帧图）：
  - 在视频资源 URL 后追加查询参数 `?poster=1` 以请求首帧图  # 需要系统已安装 ffmpeg
  - 页面已内置懒加载逻辑，进入视口后自动请求资源与海报  # 无需手动添加参数

### 端口与网络
- 默认端口固定为 `19992`  # 当前版本不支持通过环境变量或参数修改
- 服务在本机网卡上监听，可使用输出的局域网地址访问  # 请确保同一局域网可达

### 常见问题
- 404：
  - 访问的路径在目标目录中不存在  # 请检查路径或回到上级目录
- 视频海报不显示：
  - 未安装 `ffmpeg` 或系统环境变量未配置  # 安装后重启终端再试
- 媒体不自动加载：
  - 该页面使用 `IntersectionObserver` 懒加载  # 滚动使其进入视口即可加载

### 安全与限制
- 无鉴权与访问控制  # 建议仅在受信任的内网使用
- 仅提供文件读取与传输  # 不会修改本地文件
- 请勿对敏感目录开启服务  # 谨慎暴露隐私内容
